## 论文定稿出图

在项目中把输入放入 `raw_data/`，在对话中指定期刊和栏宽。当前仓库的默认 genome `g-0010` 启用了 `statistical-analysis`，沿用已有的 `figure-style` 和 `scientific-visualization`。已有工作区可以在插件页启用统计技能。

- `run_python` 的 `publication: true` 需要 Linux 容器。容器以只读方式挂载 `raw_data/`，程序成功后只回写 `deliverables` 中列出的 `figures/` 或 `processed/` 文件。处理缓存可以存入 `processed/`，绘图脚本仍能从原始数据重跑。
- `evoscholar_fig.save_publication` 同时输出 PDF、从该 PDF 渲染的 PNG、可重跑的脚本和 `.analysis.json`。期刊规则包决定画布宽度和字号。检查覆盖实际 PDF 尺寸、字体嵌入、Type 3、渲染缺字及内嵌位图的有效 DPI。`figure_check` 另外返回检查预览，保留定稿时写出的 PNG。
- 在真实容器里核验了 Nature 单栏 **89 mm** 的 CSV 误差棒曲线，以及 IEEE 双栏 **182 mm**、内嵌位图最低 **400 DPI** 的 MAT 热图。用最终脚本在新容器中重跑，两张图的 PNG 和分析日志一致。样图嵌入的是沙箱里的 DejaVu Sans，投稿时可从 PDF 检查结果核对实际字体。

入口见 [定稿工作流](../skills/statistical-analysis/references/publication.md)、[Python 出图实现](../python/evoscholar_fig.py) 和 [执行器](../packages/core/src/docker-executor.ts)。

## Python 算子的作用域、版本和审批

`forge_skill` 将通过沙箱测试的代码、测试和说明保存到 `skills/<name>/revisions/vN/`。项目作用域由宿主提供，独立工作目录会话以目录划分。输入格式记录路径参数名、后缀和开头最多八行 UTF-8 表头。执行前读取实际文件，匹配成功后才加载对应版本的 Python 函数。

`run_skill` 传 `name`、`version` 和 `args`。轨迹记录执行版本。新试用版可与生效版并存，下一回合刷新技能索引。试用版在锻造会话之外的两个会话执行成功后，可以由用户批准转正。执行成功表示程序完成，科学结果仍由数据验收判断。在「插件 → 技能详情」可以回滚到已批准版本。历史已生效算子继续可用，缺少作用域的历史试用算子需要重新锻造。

入口见 [锻造和调用](../packages/core/src/evolve/kernels.ts)、[作用域与技能索引](../packages/core/src/skills.ts)、[版本回滚](../packages/core/src/plugins.ts) 和 [工作台操作说明](in-loop-evolution.md#5-可执行技能锻造)。

## 「轨迹 → 时间线」的证据卡

页面顶部的「光谱算子迁移验证」是本机容器实跑生成的合成样例。三处入口分别打开 NumPy 原始异常、算子 v1 的锻造和试用记录，以及两份留出谱与正常谱的运行输出。版本页可展开查看源码和训练样本测试，验收页保留参考值、设定容差、格式拦截及文件一致性结果。

新锻造版本使用持久的发布 ID 关联审批和执行记录。同回合有已记录的工具报错时，证据卡按会话和调用 ID 定位最近一条原始报错。人工批准取自审批事件，执行输出取自宿主记录，弹窗可打开原会话。普通会话中的成功执行显示为执行记录。样例的留出结论由独立对照测试生成。

| 合成样本 | 峰位（nm） | 半高全宽（nm） | 结果 |
| --- | ---: | ---: | --- |
| `held-a.csv` | 1550.205 | 0.11800964 | 在设定容差内 |
| `held-b.csv` | 1549.875 | 0.19600407 | 在设定容差内 |
| `normal.csv` | 1550.045 | 0.08400849 | 两项与参考流程完全一致 |

普通单表头 CSV 读取在留出集通过 **0/2**，试用算子通过 **2/2**。异格式正常谱和跨项目调用被拦截。四份原始输入的字节对照一致。样例中的 v1 处于试用状态。

## 本地启动与复验

在仓库根目录运行。Python 依赖未准备时用 `npm run setup:python`。已安装的旧沙箱镜像需重建一次。

```bash
npm run build
npm run sandbox:build
npm test
npm start
```

单独复跑光谱对照，并把这一轮的原始记录导出到临时文件。确认结果后，可用该文件更新随应用附带的样例。

```bash
EVOSCHOLAR_SPECTRAL_EVIDENCE=/tmp/spectral-operator-evidence.json \
  node --no-warnings --test --test-name-pattern='scoped spectral operator' \
  packages/core/dist/plugins.test.js
```

本机验证通过了 TypeScript 构建、108 项 Node 测试和 54 项 Python 测试。一次全量运行中的 Linux 容器冒烟失败，重跑时全量通过。Chrome 验证了三处样例入口、真实证据 API 接入、400 px 窄屏和原会话跳转。
