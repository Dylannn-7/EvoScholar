## 1. 核心思路

AXON 是展示页，EvoScholar 是要长时间干活的对话工作台。所以不照搬布局，只搬三样东西：

1. **背景层**：全屏粒子云 + 鼠标流体，作为工作台的「环境」，而不是主角。
2. **UI 语言**：纯黑底、等宽字、小号大写标签、方角灰色 chip、1px 分隔线、紫色 `#aa88ff` 小标题、`[方括号]` 式区块名、右上角圆形计数器。
3. **克制的动效**：除粒子外没有入场动画；悬停只做 300ms 透明度变化。

再加一层 EvoScholar 自己的意义：**粒子云的状态反映智能体和进化的状态**（见 §5），让背景不只是装饰。

## 3. 设计令牌

```
--accent: #aa88ff   区块标题、待审批、激活态描边
--text:   #dddddd
--muted:  #8a8a8a
--chip:   #1c1c1c
--line:   #2a2a2a
--panel:  rgba(0,0,0,.72)   对话气泡、侧面板、代码块底（新增）
--danger: #ff6b6b           预算超限、拒绝按钮（新增，只在必要时出现）
背景 #000，html/body 100% 高，overflow hidden（滚动只发生在会话列表、线程、面板内部）
```

**字体**：等宽栈要补中文回退，否则中文会落到衬线体：
`"SF Mono", "Menlo", "Consolas", "Liberation Mono", "PingFang SC", "Noto Sans Mono CJK SC", "Microsoft YaHei", monospace`

- 标签、chip、区块名、按钮：13px（chip 11px），大写，letter-spacing .02em，line-height 1.35 —— 与 AXON 一致。
- **对话正文例外**：14px、line-height 1.65、不转大写；中文长段落 13px 太累。
- 代码 / JSON / TikZ 源码：13px，不透明 `--panel` 底，1px `--line` 边框，圆角 2px。

## 4. 可读性规则（AXON 没有的问题）

- `mix-blend-mode: plus-lighter` **只用于**品牌、chip、右栏标签、区块标题这类短文本。
- 对话气泡、输入框、审批卡、侧面板、表格、图片一律不混合，用 `--panel` 半透明黑底 + `backdrop-filter: blur(6px)`，保证粒子再亮也能读。
- 有会话打开时，粒子层整体降到约 40% 亮度（在 point shader 里乘一个 `uDim` uniform，过渡 600ms）；欢迎页 100%。
- 用户在输入框打字时，鼠标流体推力降到 0.15，避免背景乱动分散注意力。
- 尊重 `prefers-reduced-motion`：直接用静态粒子帧（只渲染一次）。

## 5. 粒子云 = 状态指示（EvoScholar 专属）

全部通过 uniform 实现，不改模拟结构：

| 状态 | 表现 |
| --- | --- |
| 空闲 | 按 AXON 参数缓慢卷曲 |
| 智能体思考 / 流式输出 | curl 噪声速度 ×2.5，粒子轻微「呼吸」 |
| 工具调用中（检索、执行 Python、出图） | 紫色粒子比例上升（`pow(random.z, 100)` 的指数降到 ~30），闪烁加快 |
| 等待用户审批 | 计数器描边呼吸 + 粒子云整体紫色调 20% |
| 新 genome 上线 | 把 origin 纹理重新随机，云「散开再重组」约 3 秒——对应 AXON「从随机位置成形」的那段，只在进化成功时出现一次 |
| 当日预算 >80% | 灰白基色向暖灰偏移；超限时紫色换成 `--danger` |

**形状**：沿用说明里的 SDF 思路（扭曲、单大开口的空心环，z 轴镜像 + 四元数旋转），自己写一个 sine-network 或「扭曲 torus + 两个软 lobe」的 SDF；可选方案是让环带一点螺旋/双链感呼应「Evo」，但不强求。

## 6. 技术取舍（与原说明的差异）

- **three.js 本地 vendor**（`apps/web/public/vendor/three.min.js`，0.150.1，MIT），不走 CDN：这是离线可用的本地工作台，且要开源。
- **不使用 AXON 的四个 R2 视频**：那是别人站点的素材，开源仓库里不能引用；会话卡片用自己生成的图或文字预览。
- **matcap 用 canvas 程序化生成**（64×64 灰色球体渐变），不嵌外部 PNG。
- **画质档位**（设置面板里可选，默认按设备自动）：高 262,144 点 / 中 65,536 / 低 16,384 / 关（纯黑 + 静态噪点）。模拟纹理边长对应 512 / 256 / 128。
- 标签页隐藏或窗口失焦超过 30 秒时暂停 rAF；回来时 `HZ` 按真实 dt 但封顶 3，防止一帧跳太远。
- 流体参数、粒子参数、相机参数全部照原说明（§7、§8、gaze 相机 lerp 0.05），放在 `fx/config.js` 便于以后调。
- WebGL2 / 浮点纹理不可用时自动降级到「关」档，UI 不受影响。

## 7. 文件改动计划（执行那天用）

```
apps/web/public/
  index.html        重排为 canvas#bg + .ui（brand / counter / tags / list / thread+composer / status / panel）
  style.css         令牌、等宽栈、chip、卡片、右栏、气泡、响应式断点
  app.js            渲染会话卡片、chip 筛选、右栏状态、计数器；向 fx 发送状态事件
  fx/config.js      全部数值参数 + 画质档位
  fx/fluid.js       GPU 流体（curl→vorticity→divergence→pressure×5→gradient→advect）
  fx/particles.js   位置 ping-pong、SDF、curl noise、点渲染、uDim/uState uniforms
  fx/shaders/*.glsl 或内联字符串
  vendor/three.min.js
```

`app.js` 与 `fx/` 之间只通过一个小接口通信：`fx.setState('idle'|'thinking'|'tool'|'approval')`、`fx.setDim(0..1)`、`fx.setBudgetLevel(0..1)`、`fx.reform()`、`fx.setQuality(tier)`。粒子层坏了不影响工作台。
