# EvoScholar 重构总计划（v2）

状态：2026-11-19 起草；A1–A9 已确认（A2 改为不设安全上限），按阶段执行中。本文件取代 `HANDOFF.md` 第 8 节的日程；循环内自进化的细节见 `docs/in-loop-evolution.md`（本计划第 3 节列出对它的修改）。

## 0. 目标

面向用户、开源在 GitHub、支持 macOS / Windows 的**个人自进化科研工作台**。用户的完整路径：

1. 打开工作台 → 设置 → 选厂商 → 选协议（默认用厂商官方协议）→ Base URL（已预填，可改）→ 填 API Key → 「获取模型」→ 「测试连接」。
2. 回到首页 → 添加本地文件夹作为项目 → 在项目下新建会话。
3. 输入框里选模型、思考程度、权限模式，可附带文件或图片，也可以 @ 引用项目里的文件作为上下文。
4. 模型执行：对话区透明，能看到思维链、工具调用、自进化步骤（回忆、反思、调整、自检）和需要用户确认的选项；背景粒子随这些步骤变化。
5. 得到交付成品。以后直接在「资料空间」找交付文件，不用翻长会话。
6. 进化沉淀出的技能和工具进入「插件」；用户也可以导入外部技能。

## 3. 对《循环内自进化》方案的修改意见

方案 v3 的主体保留：
- 会话覆盖层；
- 四类反馈；
- Beta 打分；
- untrusted 隔离（外部来源的条目不能自动转正）；
- 可执行技能锻造。

修改和补充如下：

1. **思维链是主角**。每回合在思维链里固定出现这几类可展开的步骤行：回忆 → 计划 → 行动 → 观察 → 反思 → 调整 → 自检 → 本回合学到。粒子状态和这些步骤一一对应（第 5 阶段）。
2. **人在环路（HITL）分三种卡片**，样式统一：
   - 权限确认：执行命令、写文件；
   - 方案选择（`offer_choices`）：口味类决定；
   - 进化确认：持久化到 genome、技能转正、规则包新增规则。

   在「完全放行」权限模式下，前两种会被跳过，但**进化确认永远需要人点**。
3. **规则包也纳入进化**。写作检查里出现的误报或漏报，以及用户的纠正，会沉淀成「规则提案」：可执行的 YAML 规则，附带来源和测试样例。提案先在本项目里试用，经确认后进入用户自己的规则包 `rulepacks/user/`，并在「插件 → 规则包」里显示来源会话。
4. **个性化记忆分层**：全局 / 项目 / 阶段。项目级记忆存在项目文件夹的 `.evoscholar/memory.md`，用户可读可改，换电脑时跟着项目走。
5. **砍掉评委打分**（方案里的 D9）。以环境信号和用户信号为主，减少额外调用。如果后面发现信号不够，再加回来。
6. **回放验证**沿用 `evolve.ts`，但只在用户点「验证并提交审批」时才运行，不再定时运行。

**左侧图标栏**：只显示图标，悬停显示名称。从上到下：

|------|------|------|
| 顶部 | 品牌 | 回首页 |
| | 工作台 | 项目树 + 会话列表（第二栏） |
| | 轨迹 | 自进化时间线：每个回合的回忆、反思、调整；记忆条目（经验 / 偏好）的得分和状态；会话覆盖层试用；待审批的 genome 候选和 diff；版本谱系与回滚 |
| | 插件 | 技能 / 工具 / 规则包三个标签。来源标注为内置、进化产生、导入。支持导入、启用 / 停用、版本回滚。出图风格作为「技能」中的一类 |
| | 资料空间 | 所有会话的产出和上传文件。可按项目 / 会话 / 类型 / 时间筛选、搜索、预览；可以把文件标为「交付物」；能从文件跳回产生它的会话 |
| | 用量 | 按时间（日 / 周 / 月）、模型、会话、项目统计 token；缓存命中率；工具调用次数。用内联 SVG 图表 |
| 底部 | 设置 | 模型与密钥（接入向导）、权限默认值、记忆、外观（粒子画质）、关于 |

**会话页**：
- 对话区完全透明，叠在粒子上，靠文字阴影和局部暗化保证可读。
- 输入框沿用 Claude Code 风格。附件区统一接收文件和图片：拖放、粘贴、点「+」都可以；图片发给模型看，其他文件上传到项目里。
- 工具栏依次是：模型、思考程度、权限模式、@ 引用文件，右侧是发送 / 停止。

**权限模式**（参照 Claude Code）：

| 模式 | 行为 |
|------|------|
| 询问 | 写文件和执行命令都要确认 |
| 自动接受编辑 | 写文件自动，执行命令要确认 |
| 计划 | 只读，先给出计划，确认后切回之前的模式执行 |
| 完全放行 | 全部自动，界面有醒目提示；仍然受沙箱限制，进化确认仍需人点 |

**全局要求**：界面不出现 emoji，图标统一用单色线性 SVG。

## 6. 不变的硬规则

- 界面文字、提示词、技能用中文；代码和提交信息用英文。
