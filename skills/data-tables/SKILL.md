# 数据表与结构化产物

## 1. 先读后写
- 先看输入文件的表头、分隔符、编码、前几行和行数（`pandas.read_csv(..., sep=None, engine='python')` 可以自动识别分隔符）。
- 编号类字段（run_id、学号、邮编）按字符串读，`dtype=str`，保留前导零。
- 日期按任务说明的格式解析（`format='%d/%m/%Y'` 之类），输出 ISO 8601（`YYYY-MM-DD`）。

## 2. 列名和键名
- 任务点名了列名或字段：**逐字照抄**，顺序一致，不加、不减、不改大小写。
- 任务没写列名时，按下面的顺序决定，不要自创：
  1. 沿用输入文件的列名；
  2. 单位换算后，把列名里的单位后缀换成新单位（`latency_s` → `latency_ms`），不要新旧两列并存；
  3. 派生统计量用简短的标准小写名：`n`、`mean`、`median`、`sample_sd`、`sem`、`count`、`cdf`、`ci95_low` / `ci95_high`；
  4. 同一个量如果在 answer.json 里已经有字段名，CSV 列用同一个名字。
- **不加辅助列**：原始值、原始单位、来源文件名、中间计数（累计计数等）、备注都不放进交付表。需要留痕就写到清洗记录或脚本里。

## 3. 行和值
- 默认保持输入的原始行序；任务要求排序时按要求的键排序（文本按字典序，数值按大小）。
- 合并多个来源时，按任务说明的先后顺序拼接，每个来源内部保持原顺序。
- CSV 里的数值不带单位字符串、不带千分位逗号；缺失值留空（不要写 NaN、null、-）。
- JSON 里数值用数字类型；比例写 0–1 的小数，除非任务要求百分数。
- 浮点结果不要提前四舍五入；需要展示时再格式化。

## 4. 去重、连接、缺失
- 去重：按任务给出的键，`drop_duplicates(subset=..., keep='first')`；记录被删行的 ID 和原因。
- 连接：左连接用 `merge(how='left', validate='many_to_one')`，先检查右表键是否唯一；连接后核对行数没有变多。
- 未匹配：保留行，补充列留空，并列出未匹配的 ID。

## 5. 可复现
- 处理代码存成 `.py` 文件（例如 `clean.py`、`make_figure.py`），一次运行即可从 inputs/ 重新生成全部产物。
- 每次运行 `run_python` 都是独立进程：中间结果写文件，不要依赖上一次的变量。
- 交付前用脚本重新读一遍产物，核对表头、行数、键集合与任务要求一致。
