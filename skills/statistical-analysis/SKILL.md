# 实验统计与出图

- 先确定采样单位、比较对象和数据依赖关系。明确配对键，区分独立样本、技术重复、训练随机种子和时间序列观测。按组记录有效样本数、缺失值和排除规则。使用原始分布、差值或残差检查与当前分析有关的假设。
- 误差棒或阴影带在图注或图例标注 SD、SEM 或置信区间及其水平、计算方法和各组有效样本量 `n`。`evoscholar_data.summarize` 提供样本 SD（`ddof=1`）、SEM 和基于 t 分布的 95% 均值置信区间，适用于相应的独立采样假设。`n<2` 时标明误差未估计，保留可画的数据点。
- 需要推断时，根据设计选择方法，报告效应估计及置信区间、检验统计量、样本量和 p 值。两独立组均值差可用 Welch t 检验，配对设计先按采样单位对齐后分析配对差值。说明多重比较的假设族，适用时用 `evoscholar_data.holm` 调整 p 值。并列的参数和秩检验应有明确用途，不能以显著性选结果。
- 需要拟合时保存模型、参数、边界或初值、残差诊断及适用的 RMSE 或 R²。以展示直接测量或描述性统计为目的的图，记录数据处理和汇总口径即可。使用现有 NumPy、SciPy 与 `evoscholar_data`。
- 论文定稿时同时读 `figure-style` 和本技能的 `references/publication.md`，用同一脚本生成成图和可复现的分析日志。
