# 证据与诚信核查

## 1. 参考文献真实性
- 有 DOI 的先按 DOI 查（`lit_verify` 或 `lit_lookup`），没有 DOI 的按题名 + 第一作者匹配（题名相似度 ≥ 0.93）。
- 任务给了本地登记表或数据快照时**只用本地数据**，不要联网。
- 比对字段：题名、第一作者姓、年份、期刊 / 会议、卷期页、DOI。报告 `observed`（稿件里的值）和 `expected`（权威来源的值）；查不到时 expected 写 null，不要编。
- 撤稿、DOI 无法解析、题名对不上都单独列出。

## 2. 引用是否支持论断
- 逐句拆出论断，到被引文献里找原文证据（`pdf_text` 带页码；扫描页用 `pdf_page_image`）。
- 判定：supported（原文直接支持）/ overstated（范围、程度、因果被放大，如样本外推、把相关说成因果、把「部分条件」说成「普遍」）/ not_found。
- 过度表述给出一句**保留适用范围**的改写：加上条件、样本、数据集或程度限定，不改变原意。
- 证据写页码（PDF 页序号，从 1 开始）。

## 3. 数字一致性
- 以原始数据 / 表格为准重新计算，不信稿件里的数字。
- 百分点（pp）与百分比（%）分开：绝对变化 = 新 − 旧（单位与原指标相同，原指标是百分数时就是百分点）；相对变化 = (新 − 旧) / 旧 × 100%。
- 明确基线是哪一个（任务指定的 baseline），方向（提升 / 下降）别弄反。
- 逐句列出与重新计算结果不符的句子 ID。

## 4. 图注与绘图一致
- 对照绘图配置 / 数据：指标名、单位、图例项、误差棒含义（SD / SEM / CI、n）。
- SVG 可以直接解析文本元素（`xml.etree`）；PDF 用 `pdf_text`。
- 报告每处不一致的字段、图中实际值、应为何值、证据（文件和元素）。

## 5. 其他
- 图像重复：同一图像在不同图里出现（可用感知哈希比对），标出位置交给用户判断，不下结论。
- AI 使用声明：按期刊 / 会议政策提示是否需要声明（如 ICLR 要求披露重要的 LLM 使用）。
- 所有结论都要能指回证据位置；证据不足时写「无法确认」。
